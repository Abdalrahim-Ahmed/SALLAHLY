# Salahny (Salla7ly)

React + Vite home-maintenance website (Arabic RTL, EN toggle, dark mode).

```bash
npm install
npm run dev
```

- Edit services / FAQs / testimonials in `src/data/`
- Brand colors and tokens live at the top of `src/index.css`
- Contact details are placeholders in `src/data/contact.js`
